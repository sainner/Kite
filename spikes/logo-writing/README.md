# Kite 手写 logo 的书写动画调试

2026-10-12，本机 macOS 27.2，Swift 6.4。

## 用途

调 Kite 手写 logo「写出来」的动画，包括节奏、书写顺序、每一笔的笔刷和节奏、结束方式。参数调定后点「复制参数」，把 JSON 拿去搬进 App。这里只是调试台，不是产品代码。

2026-10-12 调定的一版已搬进 App：`app/Kite/UI/HandwrittenLogo.swift` 里的 `LogoInk`（笔画路径、行书笔刷、各笔节奏）。App 端按速度计时，指针进到侧栏标志栏时写一遍，速度后来在 App 里又提到了 480 单位/秒。

## 运行

```sh
./build.sh                                   # 编译并打开窗口，默认读 ~/Desktop/line-logo.svg，文件一保存就重新载入
./build.sh --snapshot <目录> [--svg <文件>] [--set 键=值] [--stroke 编号:键=值] [--order 3,2,1]
                                             # 不开窗口：把写到 0%～100% 和结束段的几帧渲染成 PNG，打印时间表；
                                             # 临时改的参数不写回偏好，笔画编号是它在 SVG 里的先后，从 1 起
```

产物在 `/tmp/kite-logo-writing/`（`SPIKE_OUT` 可改），不进仓库。窗口里空格播放/暂停，底部时间条可以拖；SVG 也可以直接拖进窗口。参数存在本机偏好里，「恢复默认」回到代码里的默认值；参数结构变了，旧设置会按默认值补齐，不会整份作废。

右侧分「节奏」「笔画」「显示」三页：

- **节奏**：全局的计时方式（按速度或按总时长）、开始前、写完停留、结束方式。
- **笔画**：上半是书写顺序，可以上移、下移，勾掉的笔不写；点一行或点画布上的笔画选中它，下半调它自己的笔刷、起笔（跟随笔刷、自定义长度和粗细、平起）、收笔出锋开关、转弯加粗、粗细倍数、速度倍数、转弯减速、起收笔快慢、落笔前停顿和反向。「把这些设置用到所有笔画」把当前这一笔的设置抄给其他笔，但写不写、反不反向各笔保留自己的。
- **显示**：背景、缩放、墨色和各种辅助线。

## 笔刷预设

只用于单线，填充轮廓的笔宽由形状决定。参数写在 `Brush.presets` 里，不能在界面上编辑。

| 预设 | 样子 |
|---|---|
| 匀线 | 等宽圆头，和 SVG 的描边一样 |
| 小楷 | 起笔顿一下，收笔出锋，略带扁笔的粗细变化 |
| 行书 | 尖起长出锋，扁笔感更强 |
| 飞白 | 14 根笔毛，底下垫一层实心笔芯；写得快、写到后段时，边上的笔毛成片断墨 |
| 扁笔 | 不收不放，粗细全由笔锋角度和行进方向决定 |

起笔长度最多占一笔的三成，出锋最多占一半，点和小勾这类短笔不会被压成细丝。不想收笔变细的那一笔，关掉它的「收笔出锋」。

「转弯加粗」不属于笔刷，逐笔设：笔宽乘 1 + 转弯加粗 ×（1 − 速度比）。转弯减速让转弯处变慢，那里就最粗；两个值都调大时，折返处会鼓起来。

## 三种 SVG

- **只有描边路径（单线）**：每个子路径算一笔，按这一笔选的笔刷预设画。
- **只有填充轮廓（笔刷字形）**：先把形状栅格化并细化出骨架，再排书写路线：起笔取最左上的端点，收笔取最右的端点；到岔口挑方向变化最小的边，通往收笔端的那座桥留到最后走，走到头就沿写过的路回笔。墨迹就是形状本身，沿路线用圆头笔画遮罩，笔宽取局部笔宽的中位数，逐步显露；写完以后撤掉遮罩。
- **填充轮廓加描边路径**：描边路径当引导线，顺序和方向按它来，遮罩宽度仍按形状的局部笔宽。自动路线排得不对时用这个。

样例 `line-logo-stroke.svg`（单线版）和 `line-logo-fill.svg`（笔刷填充版）都取自 2026-10-12 桌面上的 `line-logo.svg`，`build.sh` 把填充版打进包里，桌面上没有文件时就用它。

## 时间模型

每一笔按弧长每 0.1 单位采一个点。速度比 = 起笔加速 × 收笔减速 × 1 / (1 + 转弯减速 × 曲率)：两头在设定距离内从 0.3 倍速平滑升到全速，曲率先做 0.6 单位的高斯平滑，这几项都是逐笔设的。时间表按速度比积分得到，再除以「全局速度 × 这一笔的速度倍数」。「按总时长」时，全局速度取成让所有要写的笔加起来正好写满设定时长的值。开始前、各笔（第二笔起先停「落笔前停顿」）、写完停留、结束段依次排在时间轴上。

## 在 line-logo-fill.svg 上的结果

- 合并缝隙取 0.15 单位时，i 的圈和主体接成一笔。书写顺序依次是：k 的竖从顶上写下来，到左下角回笔，绕 k 的圈，走弯，写 i、t、e，最后一笔写 i 点。缝隙取 0 时 i 的圈会单独成一笔；取到 0.4 会把 k 圈和 i 圈的窄眼糊上，遮罩发胖。
- 写完前最后一刻遮罩基本盖满，只有两处针尖大的缝露不出来，写完撤掉遮罩后补齐。

## 已知限制

- 自动路线靠启发式。笔画交叉多、并笔多的字形可能排错，这时可以换起笔端点、把某笔反向，或者画引导线。
- 遮罩是圆头笔，经过交叉处时会提前露出另一笔的一小块。
- SVG 里的 transform、style 属性、arc 的弧度都不处理（arc 按直线连到终点）。
