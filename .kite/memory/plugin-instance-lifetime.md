  type: project

2026-10-01 用户明确：无需后台任务的实例应该随着窗口关闭而回收。此前“关闭窗口一律保留插件实例”的决定不再普遍适用；侧栏底部保留无窗口实例的入口，也不意味着每种实例都必须在关闭窗口后保留。

**Why:** 用户在了解文件插件没有后台工作、关闭窗口仍保留实例后，提出按实例是否需要后台存续区分回收行为。
**How to apply:** 后续设计插件生命周期时落实这一区分，多视图实例应以最后一个窗口关闭为判断点；最小化仍保留窗口。agent 会话已有独立保留约定，不能只按当前是否执行任务判断删除。2026-10-01 用户认可并要求实施两类生命周期：随窗口回收、独立存续。文件适用前者，agent 和持久待办适用后者；实际接口和清理语义以 `docs/Agent与插件契约.md` 为准。
