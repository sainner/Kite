---
name: preserve-ui-on-data-integration
description: App 接真实数据时保留已做好的界面结构，不另换空状态页面或控件布局
metadata:
  type: feedback
---

给现有 App 接真实数据时，沿用原来的卡片工作区、侧边栏和控制区布局。没有后端会话也保留同一工作区的空白会话状态，不用另一套页面替换整个主界面；新增操作入口遵循现有的尺寸和布局。

**Why:** 用户在这次接入后指出 Mac「整个界面和之前的完全不一样」。原有界面已花时间调整，接数据不应顺带重做外观。
**How to apply:** 接接口时优先替换数据来源和动作回调；遇到空数据、未连接、尚未实现的操作，按原界面结构表达状态。不能用示例会话伪装真实数据，也不能把编译通过当作原有界面得到保留的依据。
