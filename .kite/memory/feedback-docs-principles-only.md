2026-10-07 用户在侧栏重设计后明确要求清理文档：“文档只写大的设计原则，界面样式、布局、交互细节不写。”正式规则见 [AGENTS.md 的知识分工](../../AGENTS.md#持久知识的分工与准入)。

**Why:** 2026-10-07 侧栏重设计时每次小改都往 docs/App.md 追加细节，用户明确反对：“这些细节不要写！有什么意义吗？”
**How to apply:** 修改文档时按上述准入规则判断，只因界面细节变化不追加说明。相关：[[feedback-docs-current-state]]。
