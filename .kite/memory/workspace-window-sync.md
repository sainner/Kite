2026-09-28 用户确认：同一工作区在 Mac 和 iPhone 上拥有同一组窗口。窗口集合、稳定 ID 和目标绑定由 kited 统一管理；添加与关闭窗口同步到各端。结合 [[workspace-thread-plugin-architecture]] 的统一设计，目标绑定为插件实例与视图，agent 也使用这个引用。分栏、尺寸、停靠顺序、当前展开项和焦点由各设备分别管理，缩小与展开只影响当前设备。关闭窗口后的实例保留规则于 2026-10-01 调整，见 [[plugin-instance-lifetime]]；无需后台任务的实例不再一律保留。

**Why:** 用户认可“同一组窗口，分别排布”更合理。Mac 可以同时展开多个窗口，iPhone 一次只展开一个；手机切换窗口不应让 Mac 的其他窗口一起缩小。
**How to apply:** 后续窗口模型和协议把服务端窗口集合与客户端布局分开。此前“窗口记录与关闭操作都只保存在当前客户端”的提议已被覆盖。重连以服务端窗口集合为准，本地布局不能复活已关闭窗口。决定不代表已经实现，实施前核对当前代码。
