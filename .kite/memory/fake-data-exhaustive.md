description: 预览覆盖当前后端真实工具与异常，未支持能力单独标注
metadata:
  type: feedback
---

界面假数据应覆盖当前后端实际可能产生的工具、成功、出错、打断、未完成及边角状态。用户于 2026-09-28 明确要求以自研 harness 为默认样本，不能继续把旧 Claude Code 样本当作当前能力。

**Why:** 避免接真实数据后才发现展示缺漏，也避免旧样本让用户误以为后端已支持某项能力。
**How to apply:** 按实际工具与显示协议核对预览代码中的样本，证据边界见 [预览与验证原则](../../docs/会话预览假数据.md)。后端扩展时重新核对，不只换工具名；未支持能力如需预览须单独标注。静态覆盖不代表流式更新、发送或重连已验证。
