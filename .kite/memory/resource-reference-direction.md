name: resource-reference-direction
description: 统一资源引用保留稳定内容身份，历史 diff 不随当前文件变化
metadata:
  type: decision
---

用户于 2026-09-30 确认统一文件、diff 与未来插件内容引用。历史引用必须打开对应那次修改，不凭路径猜最近版本；用户明确不需要引用中的 old/new 区分。窗口只是呈现入口，未来应能定位插件内容中的某一部分。

**Why:** 要从正文和工具摘要直达内容，同时可靠回看历史修改。
**How to apply:** 扩展引用类型时保持稳定内容身份与统一宿主路由。契约由 [资源引用](../../docs/资源引用.md) 维护，具体手势、图标与颜色由代码表达。
