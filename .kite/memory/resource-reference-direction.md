用户于 2026-09-30 确认开始实施统一资源引用：正文与工具摘要识别 `path:行范围`、`path:diffId`，渲染成可点击的文件名；正文保留较小的同色文件图标，工具行摘要不显示引用图标，引用文字加下划线并使用次要文字色，失败时随工具行显示红色，不用主题色。diffId 明确标识哪一次修改，可追加行范围。用户明确不需要旧侧、新侧的引用设计，不在引用中携带 old/new。网页使用各站 favicon。文件图标和 favicon 在 Mac 与 iPhone 共用字号 85% 的高度规则，随文字缩放，并以相邻文字的基线为基准，Mac 不偏移、iPhone 下移 1pt；图标后固定留 2pt 间距。多次修改同一文件时，历史引用必须打开各自那次差异。

Mac 悬停可点击的引用时应显示手形光标，普通正文仍可选字。

iPhone 消息里的单击留给引用跳转；长按不动呼出操作栏，长按后继续拖动沿用选字交互并收起操作栏。用户反馈原先单击操作栏妨碍了正文引用点击。

用户希望后续可引用插件窗口中的某个部分，因此引用以资源与稳定内容标识为目标，窗口只是呈现入口。文件浏览和预览收拢到同一个文件窗口，内部切换文本、渲染与 diff。

**Why:** 用户要直接点击工具摘要和模型正文跳到对应内容，同时保留回看历史修改的能力，避免引用协议与某个会话组件或窗口布局耦合。
**How to apply:** 新引用类型复用展示和宿主路由，不凭路径猜最近一次修改；格式和当前实现边界核对 `docs/资源引用.md`。
