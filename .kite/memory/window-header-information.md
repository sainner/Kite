description: 窗口标题统一两行，突出会话名称而非工作区名或窗口类别
metadata:
  type: decision
---

用户确定 Mac 与 iPhone 窗口标题均左对齐两行，前面不放图标。会话名称为主标题，窗口类别“代理”为次级信息；文件次级信息为可点击的目录路径。会话名称可点击重新生成，并带小刷新图标提示。

**Why:** 用户希望同一工作区中的 agent 能靠会话名称区分；2026-10-04 明确纠正信息层级，把会话名称放在窗口类别之上。
**How to apply:** 扩展窗口标题时保持此层级，不用工作区名代替会话名称；刷新图标是尾部操作提示，不等于恢复标题前图标。具体控件与字号查 [App 说明](../../docs/App.md)。
