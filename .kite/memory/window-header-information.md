用户确定 Mac 与 iPhone 窗口标题左对齐，主标题前不放图标，会话名称为主标题。2026-10-06 用户先后试过“图标 + 窗口类型”的 pill 和放在主标题上方的文字型次级信息，最终决定只保留标题、去掉次级信息；文件窗口标题为当前文件或目录名。重新生成标题只由标题右侧的刷新图标触发，悬停等可交互样式只作用在图标上，图标与标题之间留出明显间距。分离的工作区窗口顶栏是单行“工作区名 / 项目”。

**Why:** 用户希望同一工作区中的 agent 能靠会话名称区分；2026-10-04 明确纠正信息层级，把会话名称放在窗口类别之上；两行标题试下来不需要，2026-10-06 改为只留标题。
**How to apply:** 扩展窗口标题时不用工作区名代替会话名称；标题区不放图标、pill 或次级信息，会话层级等信息若再需要，先和用户确认放在哪里。标题栏只在可点元素上避让卡片拖动。具体控件与字号查 [App 说明](../../docs/App.md)。
