2026-10-07 用户调整 Mac 与多窗口布局的标题栏：最前放状态圆环，标题下方显示窗口类型；当天稍晚又决定标题前设公共信息区，侧栏入口出现时与信息区合成一块玻璃，并把 iPhone 会话窗口底部的状态 chip 也收进这个信息区，标题下的窗口类型也两端统一。这取代同日“iPhone 单窗口保留底部 chip”的安排。

2026-10-08 用户要求手机端会话 header 移除独立侧栏图标，把打开侧栏的功能放到圆环上；预览后决定移除圆环外的玻璃面板。这是上述合并入口安排在手机端的后续调整。

2026-10-09 用户要求会话窗口标题下的副标题显示会话所用的上下文模板（取代「会话」二字）；还没有对话的新会话在模板名后跟下拉箭头，点开选模板，取代原先空白页中间的模板胶囊；这时标题后的重新生成箭头不显示。

**Why:** 用户希望同一工作区中的 agent 能靠会话名称区分，会话名称的层级高于窗口类别；状态入口放在公共区域，任何窗口排在第一个时行为一致，两端不再分别维护。
**How to apply:** 扩展标题时不用工作区名代替会话名称；状态信息放标题前的公共信息区，不另在底部或各窗口自拼入口。窗口类型同样两端都显示在主标题下方，会话窗口例外，副标题是上下文模板。标题栏只在可点元素上避让卡片拖动，具体呈现核对当前代码与用户预览。
