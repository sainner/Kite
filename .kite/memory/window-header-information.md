用户确定 Mac 与 iPhone 窗口标题均左对齐两行，主标题前不放图标。会话名称为主标题。2026-10-06 用户试过把次级信息统一成“图标 + 窗口类型”的 pill，觉得不行，改回文字型次级信息，随后又去掉了前面的窗口图标：文字由每个窗口自定，不给时显示窗口类型，放在主标题上方；未来会话窗口要在这里显示会话层级，如“主会话”“界面开发/子会话”。文件窗口主标题为当前文件或目录名，次级信息为目录路径。重新生成标题只由标题右侧的刷新图标触发，悬停等可交互样式只作用在图标上。分离的工作区窗口顶栏是单行“工作区名 / 项目”。

**Why:** 用户希望同一工作区中的 agent 能靠会话名称区分；2026-10-04 明确纠正信息层级，把会话名称放在窗口类别之上。
**How to apply:** 扩展窗口标题时保持此层级，不用工作区名代替会话名称；标题区不放图标，也不再用 pill 样式。标题栏只在可点元素上避让卡片拖动。具体控件与字号查 [App 说明](../../docs/App.md)。
