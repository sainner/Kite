**状态：** 2026-10-16 已实现（契约见 [实例操作 · 终端](../../docs/实例操作.md#终端)），待用户在 Mac、iPhone、iPad 上手测。
**来源：** 2026-10-16 用户定的方向：无窗口的插件实例就是后台进程，在停靠栏显示成小头像；用户开的终端是不加沙箱的登录 shell；进程结束后没有窗口就回收；agent 的长命令按 Claude Code 的方式转到后台终端（超时、插话、显式参数，结束时通知）。

未决：
- 真机验收：SwiftTerm（1.18.0，1.19 起带构建插件，xcodebuild 要额外信任，没升）窗口的键盘、颜色、选字与复制，停靠栏里后台终端的小头像，关窗口飞回停靠栏。2026-10-18 改成一个实例一个窗口，输出与网页在同一窗口里切换（标题栏右组最前面），各自第一次显示才接上，切走后留着但不绘制（终端 isHidden，网页摘下 WebView、WebPage 留着）：要验切回网页时跳转、滚动是否还在（摘下再挂回同一个 WebPage 未经实测），藏起来的终端不再收按键（Mac 交出第一响应者、iOS 收键盘）。
- 两台设备同时开一个终端时，PTY 尺寸跟最近输入的那台，另一台按自己的窗口尺寸显示，折行会错到它输入为止；要不要像 tmux 那样裁剪或缩放待定。
- 终端归 kited：kited 重启或升级时终端随之结束。要不要单独起一个 PTY 宿主让它活过 kited 重启，没定。
- agent 转到后台的命令只有输出没有输入，Codex 那种往后台进程写 stdin 的能力没做。
- 网页视图（2026-10-16 接上）：沙箱里不许监听也不许连本机端口（上游 `allowLocalBinding` 会连带放开连本机全部端口，包括 kited 的接口，没用）；agent 的开发服务器走沙箱外命令（事先允许或申请后批准）运行才有网页可看。消息链接里的路径还没带进网页视图。

**完成条件：** 用户手测通过，以上各项有了决定（做或明确不做）后删掉本条。
