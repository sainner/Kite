**状态：** 2026-10-16 已实现（契约见 [实例操作 · 终端](../../docs/实例操作.md#终端)），待用户在 Mac、iPhone、iPad 上手测。
**来源：** 2026-10-16 用户定的方向：无窗口的插件实例就是后台进程，在停靠栏显示成小头像；用户开的终端是不加沙箱的登录 shell；进程结束后没有窗口就回收；agent 的长命令按 Claude Code 的方式转到后台终端（超时、插话、显式参数，结束时通知）。

未决：
- 真机验收：SwiftTerm（1.18.0，1.19 起带构建插件，xcodebuild 要额外信任，没升）窗口的键盘、颜色、选字与复制，停靠栏里后台终端的小头像，关窗口飞回停靠栏。2026-10-22 网页移出终端（见 [[todo-preview-plugin]]），终端窗口只剩输出。2026-10-18 接上代码块的「在终端中执行」：测试只用 /bin/sh 和 zsh -f，要验用户真实的 zsh 配置（启动慢、提示符插件）下「等行编辑器打开括号粘贴、最多 10 秒」的判断是否可靠、命令是否只显示一遍。
- 两台设备同时开一个终端时，PTY 尺寸跟最近输入的那台，另一台按自己的窗口尺寸显示，折行会错到它输入为止；要不要像 tmux 那样裁剪或缩放待定。
- 终端归 kited：kited 重启或升级时终端随之结束。要不要单独起一个 PTY 宿主让它活过 kited 重启，没定。
- agent 转到后台的命令只有输出没有输入，Codex 那种往后台进程写 stdin 的能力没做。
- 网页（2026-10-16 接上，2026-10-22 移到预览）：沙箱里不许监听也不许连本机端口（上游 `allowLocalBinding` 会连带放开连本机全部端口，包括 kited 的接口，没用）；agent 的开发服务器走沙箱外命令（事先允许或申请后批准）运行才有网页可看。消息链接里的路径还没带进网页视图。
- 跨端口网页（2026-10-21 改，待验）：其他设备上为本工作区全部运行中终端与预览的端口开同号转发（127.0.0.1 与 ::1），2026-10-22 起设备打开着工作区期间就开、不再要求开着网页视图；工作机 kite-net 转交时保留页面所用的本机主机名，原来一律改成 localhost。起因：在 WorkStation 上看 Mac mini 上的 crevo 灵感库详情页（4011 页面嵌 `http://[::1]:4012` 的回放 iframe，票据接口按 Host 核对来源）时报 400、退回截图，agent 在 Mac mini 本机 Chrome 里复现不出来。验收：Mac mini 换上新版 kite-net、这台 Mac 换上新 App 后，在 Kite 里打开详情页，iframe 应显示真网页。

- 预置脚本 2026-10-22 已移到预览插件的「目标」（`.kite/preview/`、preview_open，终端去掉了 terminal_run），验收点见 [[todo-preview-plugin]]；终端回到用户 shell 与 agent 的后台命令，进程托管照旧由终端插件做（预览实例的进程也在这里，状态同在 state.terminal）。

网页已移出终端：终端标题栏的「打开网页」开浏览窗口（浏览即原文件插件，10-23 合并），上面网页的几项验收在浏览与预览里做。
