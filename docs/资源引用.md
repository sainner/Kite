# 资源引用

消息正文与工具摘要共用资源引用。引用描述目标和定位，宿主负责打开窗口；渲染组件不直接操作文件服务、插件实例或窗口布局。

## 写法与身份

| 写法 | 目标 |
| --- | --- |
| `src/file.ts` | 当前文件 |
| `src/file.ts:10-20` | 当前文件第 10–20 行 |
| `src/file.ts:diff_a81` | 指定历史差异中这个文件的首个改动 |
| `src/file.ts:diff_a81:10-20` | 指定历史差异，定位修改后的文件第 10–20 行 |
| `https://example.com/path#section` | 网页及网页锚点 |

行号从 1 开始，范围包含首尾。引用不区分旧侧和新侧；diff 行号统一按修改后的文件计算，整文件删除用不带行号的 diff 引用查看首个改动。裸路径采用保守识别；含空格或保留字符时使用 Markdown 链接并编码目标，例如 `[说明](docs/my%20file.md:1-20)`。行内代码中的路径可以识别，代码块保持原文。已有 Markdown 链接和裸引用最终使用同一处理入口。

文件简写按照消息所属的工作机与工作区解释，完整内部链接使用 `kite://file`，查询字段为 `machine`、`workspace`、`path`，可选 `diff`、`start`、`end`，字段用 URLComponents 编码。显示名称不承担身份。当前宿主只打开当前工作机和工作区内的引用，跨工作区、未知类型会明确报错，不交给系统误打开。

文件与 diff 引用在正文中显示文件名与同色文件图标；工具行摘要只显示带下划线的可点击文件名，不显示引用图标；使用次要文字色，失败时显示红色。文件图标与 favicon 共用尺寸规则：两端高度统一为字号的 85%，保留宽高比；两端都随文字字号缩放。原始 JSON 详情保留完整字符串，只附加链接。网页保留链接文字，使用站点 favicon；按站点缓存，读取失败回退网页图标。Mac 在缓存图标时去除外圈透明留白，使设定高度对应可见图形。图标底边以相邻文字的基线为基准；Mac 不偏移，iPhone 向下微调 1pt，图标后的间距固定为 2pt，不使用普通空格撑开。Mac 悬停引用文字时显示手形光标，命中范围沿用 SwiftUI 的实际文字排版，普通正文保留系统选字光标。图标资源不写进 transcript，不改变链接目标。解析与窗口重排不执行引用跳转。

## 历史差异

`patch` 执行器为一次调用生成 `diff_<UUID>`。每个成功写入的文件保存 `{path, before, after}`，新增文件的 before 为 null，删除文件的 after 为 null。记录放在服务数据目录 `diffs/<workspaceId>/<diffId>.json`，原子替换并同步落盘。单独运行 harness 时保存在会话目录的 diffs 下。

只有实际写入且完成差异保存的文件进入结果的 `diff: {id, paths}`；规划失败不产生引用，部分写入失败仍返回已完成文件的引用。差异记录的内容来自本次补丁的真实前后正文，当前工作树后续变化不参与历史预览。命令工具没有可精确归属的历史差异时不伪造 diffId。

工具 output 同时返回可供模型直接使用的 `path:diffId`。结构化 diff 字段经 journal、显示协议和 App 保留，工具摘要直接用它构造引用，不从成功文字中反推。完整差异通过有授权校验的 `files.diff {instanceId, diffId}` 按需读取，不将前后全文塞进消息流。

引用不存在时报告错误；目标存在但指定行不再可用时展示内容并提示定位失效。只知道路径的 `path:diff` 不能确定历史版本，因此不作为有效的历史引用。当前工作区的动态 diff 不混用历史 ID，尚未提供对应入口。

## 文件窗口

`kite.files` 统一提供一个 files 视图，包含目录、原文、Markdown 预览与历史 diff。独立的 `kite.preview` 占位定义已撤下。窗口复用已有文件实例；没有实例时通过现有窗口创建接口创建，保留请求 ID 的重试语义。

所选路径与可选 diffId 保存在文件实例 state，共享且持久。`files.select` 可选择已不存在于当前目录的历史文件，前提是它存在于指定差异记录。目录位置、行号范围、滚动、高亮、显示方式与焦点按设备管理。窗口的打开与关闭仍按已有工作区窗口协议同步。

点击工具摘要引用只跳转；工具名及其余展开区域继续打开原始 JSON。iPhone 正文中的引用用单击打开；消息操作栏改为长按显示，继续拖动则收起操作栏并选字。已有选区时单击只取消选区，不执行跳转。diff 视图仍保留修改前后的行号用于阅读对比；引用定位使用修改后的文件行号，不能用屏幕行号代替。

## 扩展边界

当前资源实现是文件、文件历史差异与网页。后续插件内容引用使用插件实例和稳定内容标识，由对应资源处理器解释定位；不把窗口 ID、像素位置或滚动距离作为内容身份。新增类型只扩展引用解析和宿主处理器，会话视图继续使用统一引用组件。

文件重命名的成对路径、动态工作区 diff、历史差异清理策略和跨工作区跳转尚未接入。当前 patch 的创建、更新和删除已经可以保存并回看；不据此声称任意 shell 修改都已归档。
