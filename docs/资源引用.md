# 资源引用

本文规定消息正文与工具摘要中的资源引用格式、内容身份和归属。引用始终描述内容及定位，窗口只是呈现入口。

## 写法与身份

| 写法 | 目标 |
| --- | --- |
| `src/file.ts` | 当前文件 |
| `src/lib` | 目录，打开浏览的目录栏并展开到它 |
| `src/file.ts:10-20` | 当前文件第 10–20 行 |
| `src/file.ts:diff_a81` | 指定历史差异中这个文件的首个改动 |
| `src/file.ts:diff_a81:10-20` | 指定历史差异，定位修改后的文件第 10–20 行 |
| `https://example.com/path#section` | 网页及网页锚点 |
| `http://127.0.0.1:3000/login` | 工作区里运行中的终端的网页，打开到这个路径，见 [实例操作 · 运行中的网页](实例操作.md#运行中的网页) |

行号从 1 开始，范围包含首尾。引用不区分旧侧和新侧；diff 行号统一按修改后的文件计算，整文件删除用不带行号的 diff 引用查看首个改动。

识别只看文字和工作区顶层的名字，不查文件是否存在：

- 路径的开头必须是工作区目录顶层的某个名字，由工作机随工作区列表给出，顶层有增减时在下次快照后更新。只有顶层名字一段时，带扩展名的文件（`README.md`）或写了结尾 `/` 的目录（`src/`）才算，`app`、`docs` 这类词不算；`and/or`、只写文件名的 `page.tsx` 也因此不识别。
- 工作机只打开工作区里的文件和目录：绝对路径在工作区目录里的按相对路径打开，在外面的不是引用，例如网址的路径 `/crevo/login`。
- 行内代码整段作为一个引用识别；整段带空白的（比如一条命令）不识别。代码块保持原文。
- 正文里从顶层名字开始往后读，路径前后可以紧挨着中文。路径在这些地方结束：
  - 空白和标点；
  - 扩展名后面接的不是英文字母、数字、`.`、`-`、`_` 或 `/`：`src/a.ts和src/b.ts` 是两个文件，`a.test.ts` 不在 `.test` 处断开；
  - 英文名字后面接中文，除非中文后面紧跟扩展名：`src/lib目录下` 是目录 `src/lib`，`docs/v2版本说明.md` 是一个文件。
  括起英文名字的成对括号、方括号算路径的一部分（`app/(auth)/[id]/page.tsx`）。纯中文的目录名后面直接接中文说明时分不开，要放进行内代码。
- 路径后面紧跟的 `:行号`、`:diff_…`、`#L行号` 一起识别；后面还接着 `:字母或数字` 的是认不出的定位，整个不识别。
- 含空格或保留字符时使用 Markdown 链接并编码目标，例如 `[说明](docs/my%20file.md:1-20)`。Markdown 链接与裸引用采用相同的目标语义。

文件简写按照消息所属的工作机与工作区解释，完整内部链接使用 `kite://file`，查询字段为 `machine`、`workspace`、`path`，可选 `diff`、`start`、`end`，字段按 URL 查询参数编码。显示名称不承担身份。当前宿主只打开当前工作机和工作区内的引用，跨工作区、未知类型会明确报错，不交给系统误打开。

引用的呈现不能改变目标身份或原始消息内容。

## 历史差异

历史差异由工作区内的稳定 diffId 标识，保留实际写入前后的全文；独立终端的差异随会话保存。当前文件后续修改或删除不改变历史预览。

`patch` 仅为实际完成且已保存历史内容的修改返回 `diff: {id, paths}` 与可用的 `path:diffId`。部分写入失败仍可引用已完成项；不得从模型输入补丁或成功文字推断修改。shell 没有可精确归属的历史差异时不提供 diffId。

完整前后正文经获准的 `files.diff {instanceId, diffId}` 按需读取，不放进消息流。结果格式见 [浏览的接口](实例操作.md#浏览)。

引用不存在时报告错误；目标存在但指定行不再可用时展示内容并提示定位失效。只知道路径的 `path:diff` 不能确定历史版本，因此不作为有效的历史引用。当前工作区的动态 diff 不混用历史 ID，尚未提供对应入口。

## 共享内容与本地定位

所选路径、历史 diff 身份与历史版本跨设备共享并持久保留。`files.select` 可选择已不存在于当前目录的历史文件，前提是它存在于指定差异记录或快照。阅读定位与呈现状态按设备管理，实例与它的当前视图按 [实例的呈现](Agent与插件契约.md#34-实例的呈现) 同步。

## 当前范围

资源引用支持当前文件、目录、文件历史差异与网页。插件内容引用、文件重命名的成对路径、动态工作区 diff、历史差异自动清理和跨工作区跳转不在当前能力内。

历史差异覆盖 patch 的创建、更新与删除，不覆盖任意 shell 修改。
