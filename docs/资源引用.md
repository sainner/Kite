# 资源引用

本文规定消息正文与工具摘要中的资源引用格式、内容身份和打开行为。引用始终描述内容及定位，窗口只是呈现入口。

## 写法与身份

| 写法 | 目标 |
| --- | --- |
| `src/file.ts` | 当前文件 |
| `src/file.ts:10-20` | 当前文件第 10–20 行 |
| `src/file.ts:diff_a81` | 指定历史差异中这个文件的首个改动 |
| `src/file.ts:diff_a81:10-20` | 指定历史差异，定位修改后的文件第 10–20 行 |
| `https://example.com/path#section` | 网页及网页锚点 |

行号从 1 开始，范围包含首尾。引用不区分旧侧和新侧；diff 行号统一按修改后的文件计算，整文件删除用不带行号的 diff 引用查看首个改动。裸路径采用保守识别；含空格或保留字符时使用 Markdown 链接并编码目标，例如 `[说明](docs/my%20file.md:1-20)`。行内代码中的路径可以识别，代码块保持原文。Markdown 链接与裸引用采用相同的目标语义。

文件简写按照消息所属的工作机与工作区解释，完整内部链接使用 `kite://file`，查询字段为 `machine`、`workspace`、`path`，可选 `diff`、`start`、`end`，字段按 URL 查询参数编码。显示名称不承担身份。当前宿主只打开当前工作机和工作区内的引用，跨工作区、未知类型会明确报错，不交给系统误打开。

文件与 diff 引用在正文中显示文件名及图标，工具摘要只显示可点击文件名；原始详情保留完整字符串。网页保留链接文字，favicon 加载失败时回退为网页图标。图标随字号缩放，不改变引用目标或消息内容。

引用支持原生文字选择，只有显式点击才跳转；解析、排版和窗口重排不应触发跳转。公共样式与交互见 [App](App.md#markdown-与资源引用)。

## 历史差异

历史差异由工作区内的稳定 diffId 标识，保留实际写入前后的全文；独立终端的差异随会话保存。当前文件后续修改或删除不改变历史预览。

`patch` 仅为实际完成且已保存历史内容的修改返回 `diff: {id, paths}` 与可用的 `path:diffId`。部分写入失败仍可引用已完成项；不得从模型输入补丁或成功文字推断修改。shell 没有可精确归属的历史差异时不提供 diffId。

完整前后正文经获准的 `files.diff {instanceId, diffId}` 按需读取，不放进消息流。结果格式见 [文件插件接口](实例操作.md#文件插件)。

引用不存在时报告错误；目标存在但指定行不再可用时展示内容并提示定位失效。只知道路径的 `path:diff` 不能确定历史版本，因此不作为有效的历史引用。当前工作区的动态 diff 不混用历史 ID，尚未提供对应入口。

## 文件窗口

引用优先复用已有文件窗口；没有时新建。窗口提供目录、原文、Markdown 与历史 diff，创建重试沿用 [窗口接口](kited.md#接口) 的规则。

所选路径与历史 diff 身份跨设备共享并持久保留。`files.select` 可选择已不存在于当前目录的历史文件，前提是它存在于指定差异记录。目录位置、行号范围、滚动、高亮、显示方式与焦点按设备管理。窗口的打开与关闭仍按已有工作区窗口协议同步。

引用点击与选字、工具详情展开互不混用，交互见 [App](App.md#阅读复制与选字)。diff 视图保留修改前后的行号供对比；引用定位始终使用修改后的文件行号。

## 扩展边界

当前资源实现是文件、文件历史差异与网页。后续插件内容引用使用插件实例和稳定内容标识，表达定位，不把窗口 ID、像素位置或滚动距离作为内容身份。

文件重命名的成对路径、动态工作区 diff、历史差异清理策略和跨工作区跳转尚未接入。当前 patch 的创建、更新和删除已经可以保存并回看；不据此声称任意 shell 修改都已归档。
