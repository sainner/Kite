# 会话流式展示要求

正文、思考摘要、工具参数和执行输出在到达时更新，同一条记录从开始到结束保持身份。本文维护可观察的展示与验收要求；事件名、字段和重连契约以 [会话显示协议](会话显示协议.md) 为准，具体布局以 [App](App.md) 为准。

## 生成、执行与回合结束

三者是不同边界。正文定稿不表示工具完成，工具完成不表示回合结束；断流不能显示为成功。上游只提供完整条目时直接显示完整内容，不虚构打字、思考或工具执行过程。

| 工具阶段 | 可见内容 |
|---|---|
| 参数生成 | 工具名、已经收到的概要字段和参数原文；缺少字段不补默认值 |
| 等待执行 | 完整参数，明确表示尚未启动 |
| 执行中 | 已收到的输出、可靠的耗时信息与执行状态 |
| 结果 | 成功、错误、未执行或未知的真实结果 |

参数未完整时不能执行。生成中取消为未执行，已启动的调用等待实际执行结果。部分写入和结果未知必须如实保留，不能因动画结束而转换成成功。

shell 输出属于工具执行流，显示受限尾部并标明截断，完整日志另存；stdout/stderr 的显示顺序不承诺恢复两条管道的原始全局顺序。read、patch 没有自然增量时直接展示结果，不人为拆字。

## 连续渲染与阅读

到达内容及时显示，不额外排队逐字播放。完整条目到达后不重字、不另增一条消息；不相关内容不能因当前消息更新而闪动或丢失展开状态。

Markdown 的未闭合代码块、链接、表格和列表仍可阅读；语法补齐时允许必要重排，最终呈现与直接解析完整原文一致。用户的选字、工具详情展开与批次身份应保持稳定。

思考只在明确的思考条目生成期间显示一行，没有正文时显示“思考中”，完成或中断后隐藏；数据保留，不计入工具数量或批次。不能从会话 running 状态猜测正在思考，也不增加状态 chip 的子状态。

底部阅读可跟随新内容，向上翻后不抢回。思考收起、Markdown 高度变化、工具详情增长与键盘变化共同遵守 [App 滚动约定](App.md#滚动)。

## 重连与恢复

短暂断线后，仍可看到当前生成内容、工具阶段与受限输出。服务重启后只恢复可靠保存的内容，未完成草稿可能消失；未收口的执行按恢复规则处理，不伪造终态。旧连接的迟到内容不能覆盖新状态；快照与增量的处理规则见 [会话显示协议](会话显示协议.md#生成与执行的流式更新)。

## 验收范围

需要跨层验证：多条目交错与最终校正不重字、参数完整前不执行、等待与执行区分、取消和思考收起、中文分块与长输出截断、重连不丢失或重复、半成品 Markdown 收口一致，以及阅读位置与展开状态保持。

动态样本用于视觉和交互预览，不证明网络、持久化和恢复正确。样本范围见 [会话预览假数据](会话预览假数据.md)，运行时验证入口见 [手动验证](../kited/test/manual/README.md)。2026-09-29 的订阅观察和解析测量保留在 [实验记录](research/2026-09-29-streaming-validation.md)。
