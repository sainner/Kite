# 会话预览假数据

Debug build 用 `--sample-data` 启动，侧栏切换场景；默认打开「插件 · 侧栏样式」。测试机用 `KITE_PREVIEW_FLAGS=KITE_SAMPLE_DATA` 编译后，从桌面重新打开也会保留样本入口。假数据走实际会话窗口，不连接服务、不执行工具，输入框可输入但不能发送。

样本沿用真实会话窗口和显示数据契约，入口见 [App 代码地图](../app/README.md#代码地图)。覆盖与后端能力分别判断：某项没有样本不代表后端不支持。

账号与 Git 操作通过本地预览请求入口返回响应，沿用真实客户端的解码和错误展示，不读取登录凭据或访问真实服务；未提供样本的请求直接拒绝。每次打开预览使用独立的场景进度，集成结果与现场状态按各自工作区或检出分别轮换，互不影响。会话、文件和窗口的视觉样本仍由本地预览状态提供。

read、patch、shell 的工具行名称统一为「读取」「编辑」「执行」。shell 样本显式填写 `description`，展示由 agent 说明命令用途的效果；read、patch 继续由界面根据参数生成摘要。

## 场景覆盖

| 场景 | 覆盖的样式与状态 |
| --- | --- |
| 点阵 · 视觉语言 | 七种终态的形变与「长成/收回点」动画、终态之间的直接形变、效果色与静息点色及透明度、整片点阵的波前；不对应任何后端数据。样本不能真正发送，发送波在「流式会话 · 动态预览」中点“重播”触发 |
| 工作区切换 | 界面开发、文档整理、日志排查、空白草稿，复用工具与消息、长文、报错和空白样本；用于反复切换不同内容和状态，后续样式场景可滚动访问 |
| chip 样式样本（四项） | 四个主状态的颜色和动效；虚构窗口下的 0%、46%、99%、100%，不代表真实模型用量 |
| 工具行 · 样式与动画 | 统一名称与摘要、补丁行数和运行时间 chip、圆角描边与同批横向虚线；成功、失败、持续执行、等待呼吸及参数生成的一帧，不执行工具 |
| 执行动画 · 文件摘要 | 两个可并发的 read 固定在执行中，长短文件引用摘要持续展示效果色像素扫掠；与工具行样本中的 shell 文字摘要对比，不执行工具 |
| 工具批次 | 同一批多个调用之间用横向虚线，同批不同工具也放在一起；不同批次之间用横向实线，不显示竖向标记 |
| 工具与消息 | 人与 agent 多轮对话、思考摘要、Kite 反馈；read 整文件/按行读取；patch 创建/修改/删除与多文件操作、未读提示、外部变化提示；shell 搜索与检查成功 |
| 工作中与排队 | 同一回合插话、多个待处理消息、并发 read 的运行中状态 |
| 长文与排版 | 长消息折叠、用户原样文字与代码、连续消息、独立的思考行；Markdown 展示含标题、嵌套列表、引用、代码块、表格、分隔线、网页与文件链接、强调与删除线，以及短/长、中英混排、相邻和带反引号的行内代码 |
| 工具与模型报错 | read 非文本/越界/文件过大；patch 目标已存在、补丁不匹配、批次部分写入失败；shell 非零退出与超时；订阅 401 与 429 |
| 停止与退回草稿 | 运行中的 shell 被打断、后续工具未启动（not_executed）、回合打断；尚未消费的消息已退回输入框 |
| 结果未知与恢复 | unknown 结果与人工恢复提示、没有落盘结果的调用显示「没跑完」 |
| 长输出与截断 | 没有正文的命令输出、退出码、完整日志路径、尾部截断、工具详情的长输出折叠、read 截断提示 |
| 回复生成中 | 未完成的文字与未闭合代码块，固定在流式回复的一帧 |
| 空白会话 | 没有历史和待处理输入时的初始界面 |
| 工作区 Git 操作 | 侧栏右键「集成到主线并推送」依次给出已推送、推送失败、冲突转交三种提示；检出现场「提交并推送」依次显示有改动、领先远程、分叉、未同步四种状态，推送返回分叉的拒绝提示；归档返回预览不可操作 |
| 设置 · Git 账号与项目 | 已绑定的 GitHub 与 GitLab（解除与添加返回预览不可操作）、GitHub 设备码验证码（本地轮询保持等待，不请求 GitHub）、添加项目时可选的两个 GitHub 仓库；项目列表含托管与正式远程各一个，迁移返回预览不可操作 |

`success`、`error`、`not_executed`、`unknown` 结果沿用真实显示映射。当前 App 将 `unknown` 映射为出错的工具行，靠结果原文和恢复提示说明未知，不在样本里另造一种更理想的显示。

## 不算已覆盖的能力

静态场景只检查可呈现的内容；动态流式场景可检查视觉与交互，但两者都不证明真实网络增量、重连、消息去重、投递重试或撤回编辑的正确性。连接与执行相关按钮保持禁用。

当前样本没有覆盖附件、多模态读取、agent 协作工具、插件 MCP 工具、真实后台任务、定时任务和自动压缩。实际能力以各后端与插件契约为准，不能把样本覆盖清单当成功能清单。

样本中的工具计数、耗时和未知状态遵守 [App 展示规则](App.md#消息思考与工具)。思考强度修改只影响本地预览；上下文百分比仅出现在明确标注的 chip 样本，普通会话保持未知，模型报错样本展示有输入用量但无窗口上限的情况。

「插件 · 侧栏样式」用于预览收起窗口、多视图实例、无窗口 agent、持久插件和纯后台插件；Web 内容是窗口占位，添加后台实例只改变样本。「流式会话 · 动态预览」通过“重播”展示思考收起、工具生成／等待／执行、输出增长与 Markdown 定稿，不访问模型或执行工具。
