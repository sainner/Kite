# 会话预览假数据

Debug build 用 `--sample-data` 启动，侧栏切换场景；默认打开「流式会话 · 动态预览」。测试机用 `SWIFT_ACTIVE_COMPILATION_CONDITIONS='DEBUG KITE_SAMPLE_DATA'` 编译后，从桌面重新打开也会保留样本入口。假数据走实际会话窗口，不连接服务、不执行工具，输入框可输入但不能发送。

当前入口是 `app/Kite/HarnessSampleTranscripts.swift`，按自研 harness 的实现维护：

- 工具定义、参数与文件输出：`kited/src/harness/local-tools.ts`。
- 命令输出与停止状态：`kited/src/harness/command.ts`、`tools.ts`。
- 显示记录与状态：`kited/src/transcript.ts`、`app/Kite/KitedClient.swift`。

read、patch、shell 的工具行名称统一为「读取」「编辑」「执行」。shell 样本显式填写 `description`，展示由 agent 说明命令用途的效果；read、patch 继续由界面根据参数生成摘要。

## 场景覆盖

| 场景 | 覆盖的样式与状态 |
| --- | --- |
| 工作区切换（前四项） | 界面开发、文档整理、日志排查、空白草稿，复用工具与消息、长文、报错和空白样本；用于反复切换不同内容和状态，后续样式场景可滚动访问 |
| chip 样式样本（四项） | 四个主状态的颜色和动效；虚构窗口下的 0%、46%、99%、100%，不代表真实模型用量 |
| 工具行 · 样式与动画 | 统一名称与摘要、补丁行数和运行时间 chip、圆角描边与同批横向虚线；成功、失败、持续执行、等待呼吸及参数生成的一帧，不执行工具 |
| 执行动画 · 文件摘要 | 两个可并发的 read 固定在执行中，长短文件引用摘要持续展示风筝与蜡笔 shader；与工具行样本中的 shell 文字摘要对比，不执行工具 |
| 工具批次 | 同一批多个调用之间用横向虚线，同批不同工具也放在一起；不同批次之间用横向实线，不显示竖向标记 |
| 工具与消息 | 人与 agent 多轮对话、思考摘要、Kite 反馈；read 整文件/按行读取；patch 创建/修改/删除与多文件操作、未读提示、外部变化提示；shell 搜索与检查成功 |
| 工作中与排队 | 同一回合插话、多个待处理消息、并发 read 的运行中状态 |
| 长文与排版 | 长消息折叠、用户原样文字与代码、连续消息、独立的思考行；Markdown 标题、嵌套列表、引用、代码块、表格、分隔线、链接、强调与删除线 |
| 工具与模型报错 | read 非文本/越界/文件过大；patch 目标已存在、补丁不匹配、批次部分写入失败；shell 非零退出与超时；订阅 401 与 429 |
| 停止与退回草稿 | 运行中的 shell 被打断、后续工具未启动（not_executed）、回合打断；尚未消费的消息已退回输入框 |
| 结果未知与恢复 | unknown 结果与人工恢复提示、没有落盘结果的调用显示「没跑完」 |
| 长输出与截断 | 没有正文的命令输出、退出码、完整日志路径、尾部截断、工具详情的长输出折叠、read 截断提示 |
| 回复生成中 | 未完成的文字与未闭合代码块，固定在流式回复的一帧 |
| 空白会话 | 没有历史和待处理输入时的初始界面 |

`success`、`error`、`not_executed`、`unknown` 结果都经过 App 当前的 `RemoteRecord.record`。当前 App 将 `unknown` 映射为出错的工具行，靠结果原文和恢复提示说明未知，不在样本里另造一种更理想的显示。

## 不算已覆盖的能力

这些是静态样本，只检查可呈现的内容，不证明网络增量、重连、消息去重、投递重试、撤回编辑、发送与滚动动画的实际行为。连接与执行相关按钮保持禁用。

当前 harness 没有附件、多模态读取、子 agent、MCP、后台任务、定时任务和自动压缩。补丁行数 chip 只统计参数里明确给出的新增与删除行，不代表实际写入结果；整文件删除缺少正文，涉及删除文件的整批计数保持未知。shell 没有工作区 diff 统计字段，不从输出原文猜测计数。运行时间使用调用的开始和结束时间，「工具行 · 样式与动画」提供明确的样本时间。动态 effort 尚未接通。上下文占比只在明确标注的 chip 样式样本中提供虚构用量和上限；普通会话样本保持未知，模型报错样本展示有输入用量但无窗口上限的情况。旧的 `SampleTranscripts.swift` 保留 Claude Code 的展示素材，但不会从本入口加载。


动态预览：Debug 样本入口现在默认打开「流式会话 · 动态预览」，控制区有“重播”。它通过 WorkThread 的真实事件入口发送 history、record、record.delta 和 state，展示思考收起、工具生成/等待/执行、输出增长、Markdown 代码块/表格定稿；不访问模型或执行工具。原有静态场景继续保留。
