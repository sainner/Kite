# 视觉风格

Kite App 的颜色、形状、动效与字号约定。界面行为与交互见 [App：界面与使用约定](App.md)，实际数值以 `app/Kite/UI/Theme.swift`、`Dots.swift` 与颜色资源为准。

## 气质

晨光里的天空与黄白格子布：浅暖白的底、天空蓝为主、日光黄点缀，配合 handcraft 的点阵。界面大面积安静，颜色集中在少数有意义的时刻。

## 颜色

### 参考色

全部彩色来自一组参考色，不混用系统默认色板。

| 名称 | 色值 | 用途 |
|---|---|---|
| Morning Breeze | `#7FA8D6` | 主题色的来源、会话窗口类别色、效果色 |
| Dewy Blue | `#A8C6E7` | 预览窗口类别色、收尾中状态、效果色 |
| Sunwashed | `#FFE08A` | 文件窗口类别色、警示色的来源、效果色 |
| Buttercup Sky | `#FFF2B2` | 插件窗口类别色，只用作面 |
| Cloud Puff | `#FFF7D6` | 浅色底的来源，只用作面 |

### 中性色

中性色只用一个色相：浅色是来自 Cloud Puff 的暖白，深色是偏蓝的炭色。层级（分隔线、占位、选中、代码底）用墨蓝 `#1E3350` 叠透明度，深色模式用雾白 `#E6EEF8`，不再叠纯黑或纯白。点阵静息点色同样是墨蓝（深色模式雾白）叠透明度，比分隔线淡。

### 语义色

| 语义 | 颜色 |
|---|---|
| 主题色：发送按钮、用户气泡、运行中、链接、新增行文字 | Morning Breeze 压深一档，保证白字可读 |
| 用户气泡 | 主题色配白字；排队中只描边 |
| 警示、停止中 | Sunwashed 深一档 |
| 错误、删除、危险操作 | 珊瑚红，参考色以外唯一的例外 |
| 新增 / 删除行底色 | 天空蓝 / 珊瑚红的淡底 |
| 浅色填充上的图标（停靠栏、最小化窗口） | 墨蓝，不用白色 |

### 效果色

执行扫掠与点阵的波共用五个效果色：Morning Breeze、Dewy Blue、Sunwashed、Sunwashed 深一档、主题色。Buttercup Sky 与 Cloud Puff 在浅底上看不清，不进效果色。扫掠和波中的同一格保持同一效果色，避免闪烁。

### 用色强度

- 大面积只用中性色；彩色出现在图标、状态、气泡、点阵事件这类小面积上。
- 平时同一视野里的彩色不超过主题蓝加一种。只有标志时刻（执行扫掠、发送波）同时用满效果色。
- 颜色过渡保持连续，不经灰，不用透明度淡出代替换色。

## 形状

- **坐标与模数**：每个 App 窗口一套坐标，原点在窗口左上角；布局模数 12 等于点阵步距。边距、缝、侧栏、停靠栏、卡片最小尺寸与默认窗口尺寸取 12 的整数倍。卡片圆角与卡片内部控件不受模数约束。
- **点阵**：每个模块中心一颗静息点，激活时长成图形；只出现在全局背景，卡片与会话内容内部不显示。形状与颜色独立变化，收回时回到同一静息点。
- **终态**：默认圆角方块，另有圆、菱形、风筝、星、心、十字。
- **步骤格**：初始配置的当前与已完成步骤完全展开，当前用 Sunwashed 黄，已完成用主题蓝；未到步骤半展开，用 Dewy Blue。
- **图形**：点阵可拼出初始配置的每步标志与步骤格，静止时对齐窗口点阵。每个标志配一个专属小动画，不旋转、不压扁：风筝浮动、光标闪烁、连接线逐格展开再收回并在相邻格间连续交接、二维码错开闪烁、文件夹加号慢闪。图形运动时格子仍留在原位；换图形时先停下，形变完成后再动。主题色为主，Dewy Blue、Sunwashed 点缀。

## 动效

| 动效 | 约定 |
|---|---|
| 形变 | 缓出，形状与颜色连续过渡；换终态直接形变，不先退回点 |
| 换图形 | 从左上到右下逐格出发，变到新图形或退回点 |
| 发送波 | 从控制区向外推进并逐渐变弱，只在背景上，被卡片盖住；初始配置完成一步时明显放慢，配合标志形变 |
| 执行扫掠 | 工具执行中唯一的动效，笔画经过时变成效果色方块 |
| 等待呼吸 | 内容透明度缓慢起伏，不加底色；背景图形等待时同样起伏 |
| 吸附 | 拖动侧栏或分栏时跟手，松手后用动画吸附到模块线 |

开启减少动态效果时没有波、扫掠和呼吸。静息时点阵保持静止。

## 字号

字号跟随系统文本样式与用户字号设置，同一语义在各处保持一致。
