# 视觉风格

Kite App 的颜色、形状、动效与字号约定。界面行为与交互见 [App：界面与使用约定](App.md)，实际数值以 `app/Kite/UI/Theme.swift`、`Dots.swift` 与颜色资源为准。

## 气质

晨光里的天空与黄白格子布：浅暖白的底、天空蓝为主、日光黄点缀，配合 handcraft 的点阵。界面大面积安静，颜色集中在少数有意义的时刻。

## 颜色

### 参考色

全部彩色来自一组参考色，代码里不直接使用系统的红、绿、橙、紫、蓝。

| 名称 | 色值 | 用途 |
|---|---|---|
| Morning Breeze | `#7FA8D6` | 主题色的来源、会话窗口类别色、效果色 |
| Dewy Blue | `#A8C6E7` | 预览窗口类别色、收尾中状态、效果色 |
| Sunwashed | `#FFE08A` | 文件窗口类别色、警示色的来源、效果色 |
| Buttercup Sky | `#FFF2B2` | 插件窗口类别色，只用作面 |
| Cloud Puff | `#FFF7D6` | 浅色底的来源，只用作面 |

### 中性色

中性色只用一个色相：浅色是来自 Cloud Puff 的暖白，深色是偏蓝的炭色。层级（分隔线、占位、选中、代码底）用墨蓝 `#1E3350` 叠透明度，深色模式用雾白 `#E6EEF8`，不再叠纯黑或纯白。点阵静息点色同样是墨蓝（深色模式雾白）叠透明度，浅色、深色都是 0.05，比分隔线淡。

### 语义色

| 语义 | 颜色 |
|---|---|
| 主题色：发送按钮、用户气泡、运行中、链接、新增行文字 | Morning Breeze 压深一档（浅色 `#5B88C2`、深色 `#4E79B0`），保证白字可读 |
| 用户气泡 | 主题色配白字；排队中只描边 |
| 警示、停止中 | Sunwashed 深一档 |
| 错误、删除、危险操作 | 珊瑚红，参考色以外唯一的例外 |
| 新增 / 删除行底色 | 天空蓝 / 珊瑚红的淡底 |
| 浅色填充上的图标（停靠栏、最小化窗口） | 墨蓝，不用白色 |

### 效果色

执行扫掠与点阵的波共用五个效果色：Morning Breeze、Dewy Blue、Sunwashed、Sunwashed 深一档、主题色。Buttercup Sky 与 Cloud Puff 在浅底上看不清，不进效果色。同一格始终取同一色，不逐帧换色。

### 用色强度

- 大面积只用中性色；彩色出现在图标、状态、气泡、点阵事件这类小面积上。
- 平时同一视野里的彩色不超过主题蓝加一种。只有标志时刻（执行扫掠、发送波）同时用满效果色。
- 颜色之间的过渡在 oklab 中插值，不经灰，不用透明度淡出代替换色。

## 形状

- **坐标与模数**：每个 App 窗口一套坐标，原点在窗口左上角；布局模数 12 等于点阵步距。边距、缝、侧栏、停靠栏、卡片最小尺寸与默认窗口尺寸取 12 的整数倍。卡片圆角与卡片内部控件不受模数约束。
- **点阵**：格 10、缝 2、点径 2，每个模块中心一颗点。一格由 shape（0 到 1）、颜色（RGBA）和终态决定；shape 为 0 时都是同一颗静息点。
- **终态**：圆角方块（圆角 17%，默认）、圆、菱形、风筝、星、心、十字。新增终态只需给出以格心为中心的闭合轮廓。
- **图形**：背景点阵可以拼出一个由圆角方块组成的图形，如初始配置每一步的标志（约 23×23 格）和步骤点，静止时格子对齐窗口点阵。图形可以分层，每个图形只配一个与它的意思相符的小动画，不旋转：浮动（几点、周期 3–5 秒，各层错开）或闪烁（熄掉时露出底下的格子或静息的点）。浮动时格子仍在原位：每个格位反算回图形坐标，按线性权重从上下相邻两格分到形变量，颜色取分得最多的那一格（不混色），与 Pigeon 格阵的亚格配准同理。换图形时先停下再形变，形变完再动起来。图形同样只在背景上，配色守用色强度：主题色为主，Dewy Blue、Sunwashed 点缀。

## 动效

| 动效 | 约定 |
|---|---|
| 形变 | 0.5 秒缓出；shape、终态与颜色一起连续过渡，换终态不经过点 |
| 换图形 | 沿对角线从左上到右下依次出发，0.3 秒内全部出发，每格按形变的 0.5 秒缓出变到新图形或退回点 |
| 发送波 | 从控制区向外每秒推进 420 点，波前半宽 36 点，一出发就渐弱，120 点内消失；波的颜色不透明度 0.4；只在背景上，被卡片盖住。初始配置完成一步时的波放慢到 0.15 倍，配合标志形变 |
| 执行扫掠 | 工具执行中唯一的动效，笔画经过时变成效果色方块 |
| 等待呼吸 | 内容透明度在 0.45 与 1 之间起伏，周期 2.8 秒，不加底色；背景图形等待时同样起伏 |
| 吸附 | 拖动侧栏或分栏时跟手，松手后用动画吸附到模块线 |

开启减少动态效果时没有波、扫掠和呼吸。静息时点阵不逐帧刷新。

## 字号

字号只用 `Theme` 里的文本样式 token，由系统按平台与用户字号设置决定大小，视图里不写点数。
