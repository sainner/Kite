# 会话显示协议 v1

App 和 `kite` HTTP 客户端只接收 Kite 显示语义；`sdk`、`harness` 和原生 journal 事件不出现在 HTTP SSE 中。原生存储保留模型恢复所需的完整内容，显示协议不反过来承担模型恢复。

## 历史与连接

`GET /sessions/:id/history` 返回：

```typescript
{
  version: 1,
  session: string,
  cursor: string,
  records: DisplayRecord[],
  pending: PendingInput[],
  state: DisplayState
}
```

类型定义在 `kited/src/transcript.ts`。记录有稳定的 `id`、毫秒时间 `at`、可选的子调用 `parent` 和一个 `block`。块包含 human、kite、text、thinking、tool_use、tool_result、interrupted、error、compacted；人消息 id 和工具调用 id 独立保留，工具结果用 `call` 关联调用。错误、打断和暂停如实显示，不补造成功结果。

`GET /events?session=:id` 首先发 `history`，主体就是上述快照，另带 `type: "history"`。随后发：

| 事件 | 客户端操作 |
| --- | --- |
| `record` | 按 `record.id` 替换原记录；首次出现才追加 |
| `pending` | 替换全部待处理输入 |
| `state` | 替换状态与能力声明 |
| `status`、`setup`、`snapshot`、`adopt`、`check`、`idle`、`error` | 管理事件，可刷新项目与会话列表或显示操作结果 |

后续事件带 `session`、`at` 和 `cursor`，SSE `id` 与 cursor 相同。服务在同一同步段订阅并生成历史快照，消除先取历史、再订阅时丢事件的窗口。订阅全部会话的 `/events` 先发 `ready`，用于确认连接后刷新列表；全局流不发送每个会话的历史。

cursor 是服务实例 UUID 加事件序号，只标识投影版本，不是原生 journal 序号或分页位置。当前不提供事件日志重放或分页；无论客户端带哪个 Last-Event-ID，每次连接都以完整 history 替换本地记录和待处理列表，再按 id 接续更新。daemon 重启后实例 UUID 改变，仍按这个规则恢复。

文字增量投影为同一个 id 的 `partial: true` 记录，完整模型条目落盘后原位替换。服务仍在运行时的重连包括 partial；daemon 重启只能恢复已经完整落盘的条目，未完成的流式草稿可能消失。只有带 itemId 的模型增量提前显示，没有 itemId 时等待完整条目，避免恢复后 id 漂移。

## 输入与控制

`POST /sessions/:id/messages` 的 `{id, text}` 使用客户端生成的稳定 id。harness 先 fsync 输入，再确认 HTTP；同 id、同内容重试不会执行两次，同 id 不同内容会报错。

输入落盘后进入 pending，真正纳入模型请求才产生 human/kite 记录并移出 pending。客户端收到 human 时也应先去掉同 id 的占位，避免相邻两帧间短暂重复。`midTurn` 表示是否并入同一回合；它以服务纳入请求的时刻为准。

`POST /sessions/:id/messages/:message/cancel` 只撤回尚未纳入请求的 harness 输入。`interrupt`、`resume` 和 `recover` 沿用现有接口。App 按 `state.capabilities` 开关发送、打断、继续和撤回，不按模型供应商判断。恢复确认仍需用户在工作机核查旧进程，App 不自动确认。

## 当前边界

- harness 的历史来自只读 journal 重放；读取不取得写锁、不修复尾行、不启动模型或工具。未完整的最后一行跳过，损坏的完整记录报错。
- 旧 Claude 会话通过 SDK `getSessionMessages` 读取主会话的基础文字、思考、工具调用与结果，并转换实时完整消息。SDK 公开的历史包装不含原始时间、origin 等全部元数据，历史 `at` 暂用会话创建时间；子 agent 完整历史、插话附件、图片和投递确认尚未补齐。因此旧会话在 App 只读，原有 HTTP/CLI 控制继续保留，不宣称完成 Claude 全量迁移。
- App 已接项目登记、会话创建/列表、历史与重连、发送、打断、继续、撤回和编辑排队消息。对话回退、分叉、附件、翻译、动态 effort、上下文占比和代码行数统计没有伪造结果；未支持的操作禁用或不显示。
- 服务仍只监听 `127.0.0.1`。Mac 与 iPhone 模拟器默认连本机 `5483`；真机、多机与认证传输另行接入，不能直接把未认证服务暴露到公网。
