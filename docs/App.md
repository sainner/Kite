# App：界面与使用约定

Mac 和 iPhone 共用原生 App，连接工作机管理工作区、会话与插件。本文说明用户能看到和操作的行为；工程配置、代码地图与构建入口见 [App README](../app/README.md)，传输字段见 [会话显示协议](会话显示协议.md)。

## 连接与工作区

导航是账号下统一的「项目 → 检出 → 工作区」，包括异机检出。检出行显示所属机器与路径，点击直接进入根工作区，下级只列独立工作区，不重复列出根工作区。无需先选择机器才能浏览项目。

App 从托管目录和本地缓存显示所有检出，同时独立连接各工作机，操作按工作区所属机器路由。单台工作机断线不会清空目录或影响其他机器；离线条目仍可选中，尚未载入的内容显示连接状态和目录更新时间，连接恢复后自动载入。地址对应的机器身份变化时拒绝操作。退出账号清除目录缓存与连接状态。

登记目录时才选择目标工作机，并选择新项目或关联已有项目。同名而不同 ID 的项目分别显示，关联项目不复制文件或执行记录。登记完成后建立根工作区；在检出中可另建独立工作区。侧栏底部显示可连接的工作机数量；尚无项目时保留设置和添加项目入口。

首次使用先完成账号与设备入网，随后直接进入项目目录：

1. 使用邮箱和密码登录、创建账号，或用 iPhone 扫描已登录设备在设置中显示的一次性二维码。
2. Mac 选择「在这台 Mac 上运行任务」或「仅远程控制」，扫码登录只在 iPhone 上提供。前者安装 kited，后者只运行 App 的网络节点；iPhone 自动作为控制端。
3. 两种角色都加入账号的网络，同账号设备不再逐台配对。进入 App 后可浏览所有已登记检出，再添加目录或创建工作区。

初始配置随宽度布局：宽窗口左侧标志、右侧标题与操作卡片；窄窗口上下排，卡片贴底。每步标志由背景点阵拼出，标题与步骤放在背景上，卡片只放操作。标志允许借用顶部背景空间，不压扁；键盘或低矮窗口仍容纳不下时退回点。等待时隐藏操作卡片，标志与标题呼吸；完成步骤时形变到下一标志并发出慢波。每个标志保留一个专属小动画，图形与动效约定见 [视觉风格](视觉风格.md)。点击输入区外收起键盘。

新设备扫描已登录设备显示的二维码完成账号登录与入网。设置的「我的设备」列出控制端和工作机，可生成五分钟内有效的一次性二维码、移除其他设备或退出本机登录。Mac 本机执行模式复用 kited 的网络节点，同一台 Mac 不重复登记。账号、授权和撤销契约见 [托管账号与设备](托管账号与设备.md)。

## 窗口与跨端布局

同一工作区共享窗口集合，添加、关闭同步到各端。分栏、尺寸、停靠顺序、最小化与焦点保存在设备上；重连后以工作机集合为准，旧布局不能复活已关闭的窗口。其他设备新增的窗口先进入本机停靠栏。

Mac 可以并排展开多个窗口，通过标题栏拖动、卡片落点及工作区外边缘分栏；放下前显示排布预览。窗口可拖入右栏、排序、拖回或点击恢复，也允许全部收起。新建与恢复优先放入右侧全高新列，横向不足则优先在聚焦卡片下方分栏，仍不足时收起一个旧窗口；窗口保持最小可用尺寸。缩小只收进本机右栏，展开让当前窗口占满内容区，关闭则同步到工作机。主窗口与分离工作区分别保留停靠顺序。

iPhone 一次只展开聚焦窗口，其他窗口收在底部栏；切换不改变 Mac 的布局。侧栏支持从左边缘拉出，底部操作区支持向上拉出，键盘输入时不触发抽屉拖动。手势可中断正在进行的转场，不能与水平滑动、正文选字互相抢占。

Mac 工作区可从侧栏拖出成为独立系统窗口，关闭后回到主窗口。侧栏可调宽、收为图标栏，并用 ⌃⌘S 切换。卡片拖动与系统窗口拖动是不同动作，控件命中区域不能被拖动层覆盖。

### 实例与窗口

工作区“添加”只创建实例，有视图时打开默认窗口，无视图时创建后台实例；新建会话本身不调用模型。无窗口但仍存续的实例保留图标，可通过菜单管理或重新打开视图。

关闭最后窗口是否回收实例由其生命周期决定。agent 保留会话及执行，文件等随窗口回收；最小化和断线不触发回收。完整语义见 [实例生命周期](Agent与插件契约.md#33-plugininstance工作区中的业务对象)。

## 公共外观与交互

窗口共用标题栏、内容和底部控制区。标题在两端均为单行左对齐，不带次级信息。会话标题为会话名称，工作区名称留在导航层；文件窗口标题为当前文件或目录名。分离的工作区窗口顶栏单行显示工作区名与所属项目。Mac 悬停窗口显示缩小、展开、关闭按钮；标题栏除按钮与可点元素（刷新图标）外都可拖动卡片。拖缝调整分栏或拖动调整侧栏宽度期间，卡片与侧栏不响应悬停和点击。

内容可从栏后滚过，标题栏与底部遮罩保持各自窗口边界，不能漏出工作区底色。布局遵守系统安全区、键盘和 Home 条，输入区与公共按钮共享命中、禁用、按压、悬停及光标反馈。玻璃轮廓与交互轮廓一致；同类入口不各自拼装一套反馈。

颜色、点阵、模数、动效与字号统一见 [视觉风格](视觉风格.md)。点阵只在背景上，卡片与会话内容覆盖它；拖动卡片不会带动背景点阵。发送消息从控制区向外发出一道波，开启减少动态效果时保持静态。

分栏和侧栏拖动时跟手，松手后吸附到模块线；分栏比例仍随可用空间变化。Mac 窗口按模块调整大小，全屏或分屏产生的不足一格余量留在右边与下边。

外观可跟随系统或选择浅色、深色，同一设备的主窗口、分离窗口及设置同步。字号跟随系统文本样式。复制等提示仅在当前窗口底部显示，并避让键盘。开启减少动态效果时，执行扫掠、呼吸和装饰性按压动效保持静态，不影响内容可读性。

## 会话输入与控制

输入区保留草稿，发送后显示投递占位。服务端确认接收与纳入模型请求是不同阶段，排队消息可以撤回、编辑，已纳入请求的消息不能撤回。投递响应丢失时使用同一消息 ID 重试，不能产生重复输入。

空闲时发送开启新回合，运行中发送为插话或排队输入。回合进行中可以停止，暂停后可显式继续；连接未建立或后端未声明能力时禁用对应操作。手动停止将未纳入请求的消息按顺序退回现有草稿前；停止响应未确认时保留重试入口并禁止新发送，其他设备不重复生成草稿。详细契约见 [会话状态机](会话状态机.md)。

当前附件、语音输入、动态推理等级、翻译、会话回退与分叉尚未接通；相应按钮禁用或隐藏。菜单和操作可用性按后端能力确定，不能从静态样本推断支持情况。

### 标题、模型与状态

点击会话标题右侧的刷新图标重新生成标题，悬停与按压反馈只作用于图标；等待期间禁用重复点击，失败保留原题并展示原因；离线、草稿与样本模式不发请求。标题行为与 HTTP 契约见 [工作机说明](kited.md#轻任务与会话标题)。

标题栏模型菜单展示当前项，选择模型时保留其他配置；若原思考档位不受新模型支持，改为新模型的可用档位；冲突或失败明确提示。型号、思考档位和配置生效边界由工作机能力声明提供；未知型号保留原值。两端菜单沿用平台原生交互。

状态 chip 与正文分开。Mac 将 chip 放在输入区操作组旁，iPhone 放在底部安全区，键盘升起或空间不足时隐藏。圆环表达执行阶段，文字表达状态、上一回合结果或恢复原因；弧长仅用于有可靠测量的上下文占比，未知时不伪造百分比。字段与含义统一见 [会话状态机](会话状态机.md#显示与统一-chip)。

更多菜单提供实例设置、授权、复制工作目录、停止或继续；恢复阻塞时提供确认入口。确认恢复要求先核查旧执行，确认本身不启动模型。

## 消息、思考与工具

用户消息靠右，排队时描边，接收后填充主题色并使用白字。正文保留原文，只将围栏代码与命令名作等宽显示；长消息由整条气泡统一折叠，展开后不再要求逐个代码块二次展开。

agent 正文使用 Markdown。思考摘要仅在生成期间显示一行，完成或中断后隐藏；历史数据保留，但不计入工具数量或批次。连续工具可折叠为汇总行，展开后按实际模型回复分批，缺少批次信息时不猜测。

工具行区分参数生成、等待、执行和结果。read 显示相对路径与行范围，patch 显示路径与历史差异入口，shell 显示调用者提供的用途；失败和未知结果用错误颜色表达。等待采用呼吸，执行统一采用效果色像素扫掠；图标、名称与摘要共同变化，信息 chip 和展开箭头保持稳定。没有动效选择菜单。

标题行的空白区域也可展开详情，文件引用仍单独跳转。详情分 input、result 两张卡片，保留原始参数、输出、截断标记及非文本结果；嵌套值紧凑展示，不重复标题行已有的名称和阶段。生成中的参数不是已经执行的工具调用。

patch 的增删行数仅来自明确的参数，不代表成功写入量；包含整文件删除等无法完整统计的情形不显示整批计数。shell 运行时间须有可靠时间信息，工作区 diff 数量不从输出猜测。

### 阅读、复制与选字

Mac 右键、iPhone 长按显示消息操作栏；单击引用直接跳转。排队消息可编辑或取消，已接收消息与 agent 正文可复制。操作栏浮在内容上，不挤动正文，点击其他位置或滚动时收起。

iPhone 长按后拖动进入选字，结束后保留选区与系统菜单；长按、选字结束不能误触引用。已有选区时第一次点击先清除选区。连续 Markdown 文本可跨段选择，代码块、表格等独立块保留自己的交互边界。

### 滚动

打开会话停在最后内容底部，不带上一轮留下的空白。用户向上阅读时停止自动跟随，回到底部后恢复；手指拖动和惯性期间不抢回滚动位置。

本次打开后发起新回合，将首条消息送到可见区顶部，为回复留出一屏空间；运行中的排队输入接在末尾，不另开空白。向上阅读逐渐去掉末尾预留空间，下一次新回合再建立。

流式内容、工具折叠、键盘及抽屉改变尺寸时，贴底阅读保持底部，阅读历史保持当前位置。内容缩短后位置不能超出有效范围，也不能因自动对齐打断系统回弹。验收依据见 [流式展示](会话流式展示.md)。

## Markdown 与资源引用

正文、标题、列表、表格和文件预览共用行内代码样式：等宽文字保留周围字重，背景随换行覆盖实际文字，图标与名称开头不分离，长名称仍可换行。排版不能破坏选字、链接或原始引用目标。

代码块统一提供语言标记、完整复制、横向滚动和长内容折叠。Shell 语言可以显示执行入口，但真实终端未接入前保持禁用。语法高亮离线完成，缺失或不支持的语言、解析失败均显示原文。复制不受折叠影响，并使用公共窗口提示。

表格使用系统衬线体，不铺独立底色，仅保留必要的表头分隔。iPhone 缺少中文宋体时从苹果按需下载并由系统缓存；等待或失败使用系统回退，不阻塞显示，后续可重试。行内代码仍使用等宽字体。

文件路径、行号、历史差异和网页链接使用统一引用，选择目标共享而定位留在设备。格式、窗口复用和历史身份见 [资源引用](资源引用.md)。

## 插件与实例管理

设置管理当前工作机的插件定义与包安装，工作区添加入口创建实例。会话更多菜单、停靠图标菜单和 Mac 标题栏菜单可打开实例设置，查看或停止插件进程、打开视图及编辑实例操作授权。无视图实例也能通过图标管理。

授权草稿保留未改动的权限，保存检查版本；冲突保留草稿，离开或重新读取前提示放弃未保存修改。实例面板绑定所属工作区与机器；同时打开不同机器的窗口时不能串用连接，原连接失效后不能保存旧草稿。未知创建结果保留原请求 ID 供重试。

harness 与 Claude 均有执行授权页面，编辑工作区读写、额外目录和网络许可。执行中、停止未确认或恢复待确认时不能保存；停止沿用会话收据和草稿退回规则。权限的实际范围由工作机核验。实例设置中的「会话配置」支持模型、思考强度、工具选择及每回合请求上限。输入区原有思考强度控件沿用拖动交互，在松手时保存；可选档位按模型能力限制。配置版本冲突保留草稿，重新载入或离开前确认放弃。配置生效边界遵循服务能力声明，授权不会因勾选工具而扩大。

上下文模板在设置中管理，空会话发送前可选择、复制并保存创建模板。模板编辑保留段落、变量与条件分支，版本冲突保留草稿；保存期间禁用发送。哪些编辑影响已有会话、标题或待投递通知，由 [上下文模板契约](harness-上下文组装.md) 统一说明。

## 自定义插件窗口

MCP Apps 视图使用现有窗口容器，复用标题栏、停靠和 iPhone 抽屉。控制区提供重新加载；状态更新或连接恢复后显示工作机的当前内容。错误明确展示，不自动重试有副作用的工具调用。

视图卸载和最小化不回收实例；关闭最后窗口按生命周期处理。网页只允许调用当前实例获准的能力，不能接触工作机凭据。插件资源、桥接限制和样例见 [Bun 插件](Bun插件.md)。

## 文件窗口

一个文件窗口提供目录浏览、原文、Markdown 预览和历史 diff，可按行定位、复制与翻页。进入目录或返回上级在当前窗口浏览，保留原来的文件选择；引用跳转优先复用已有窗口。

所选文件及历史 diff 身份由实例共享，目录位置、页码、定位与显示方式留在设备。另一端改变选择后显示新的目标，旧响应不能覆盖新选择。最小化和重连保留选择，关闭最后窗口后重新添加则创建新实例；工作区文件与历史 diff 保留。

当前支持最多 2 MiB 的文本，目录与正文分页读取，非文本、删除、超限和路径越界均显示错误。符号链接可列出但不提供目录跳转。当前没有文件编辑器或后台文件监听，刷新主动读取最新内容。真实终端仍为占位。

## 开发预览与验证

普通启动连接真实工作机。Debug 可用 `--sample-data`，需要测试机从桌面反复启动时用 `KITE_PREVIEW_FLAGS=KITE_SAMPLE_DATA` 构建；初始配置用 `--onboarding-preview` 或 `KITE_ONBOARDING_PREVIEW` 预览，不连接服务，从未登录开始走完整个流程，登录、扫码与入网只模拟等待（扫码页轻点取景框即算扫到），入网完成后回到开头，右上角可随时重新开始；Release 不加载样本。样本不创建真实实例，也不调用模型；动态样本用于视觉和交互预览，不证明网络时序正确。场景清单和覆盖限制统一见 [会话预览假数据](会话预览假数据.md)。

编译命令与依赖见 [App README](../app/README.md)，跨层及原生运行时验证见 [手动验证入口](../kited/test/manual/README.md)。界面效果由用户预览确认。

## 签名

工程使用自动签名。本机配置有效开发团队并连接测试 iPhone 后，按设备 ID 构建，再用 Xcode 或 `devicectl device install app` 安装、`devicectl device process launch` 打开。签名身份以工程当前配置和本机证书为准，不在文档复制一份机器状态。
