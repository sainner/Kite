# Kite App

Mac 和 iPhone 共用一个 SwiftUI 工程、一个多平台 target。

```
app/
├── Kite.xcodeproj
│   └── xcshareddata/xcschemes/Kite.xcscheme   共享 scheme，命令行和 Xcode 用同一个
└── Kite/                                      源码和资源
```

布局：一个会话就是一个窗口组（`Workspace`，在 `Tiles.swift`）：有哪些窗口、Mac 上怎么排、聚焦哪个。Mac 把它们排成卡片（`TileViews.swift`），按住卡片标题栏拖出去，它脱离布局变成跟着指针的圆，落到别的卡片上时用占位预览放下后的排布；iPhone 一次显示聚焦的那个，页签切换（`PhoneLayout.swift`）。Mac 主窗口左边是侧边栏（会话列表和底部的 action 区，拖右边的缝调宽度，拖到很窄收成一列图标，⌃⌘S 切换），会话从侧边栏拖到主窗口外面分离成独立窗口（`DetachedSession.swift`），关掉后回到主窗口。卡片和缝上不拖窗口，拖窗口交给侧边栏这些空白处（`MouseDragArea.swift`）。红绿灯按钮那一条多高、让出多宽，从 AppKit 的安全区读（`WindowChrome.swift`），不写死。尺寸和颜色集中在 `Theme.swift`。

每个窗口都是同一个骨架（`PaneWindow.swift`）：浮在上面的标题栏、内容、浮在下面的控制区，内容从两者后面滚过去，标题栏后面垫系统的滚动边缘效果（软边），iPhone 上再叠一层从窗口顶边起、伸过标题栏底边一点的渐变遮罩（软边只模糊不提白，标题会看不清；不透明度 1 − h²，h 是离窗口顶边的距离占整段高度的比例，和底下那层对称；Mac 上标题栏矮、没有状态栏，不叠），控制区后面垫一层渐变遮罩（窗口底色从控制区顶边的全透明过渡到不透明，伸过 Home 条那一截到窗口底边；不透明度是 1 − h²，h 是离窗口底边的距离占整段高度的比例）。控制区是一张液态玻璃卡片，左右留边，靠近窗口角的两个角和窗口圆角同心（窗口用 containerShape 给出形状），底下贴着 Home 条让出的安全区，没有安全区时（Mac 的卡片、iPhone 拉开抽屉）离底边留一点，键盘升起来时离键盘也留这么多。SwiftUI 的安全区分 container 和 keyboard 两区，但只能按区忽略，读出来是合在一起的；Home 条那一截从 UIKit 的安全区读（UIKit 的安全区不含键盘），多出来的就是键盘；这一比在屏幕那一层做。控制区底下的安全区里放状态信息，只看不点：iPhone 上让小横条藏起来，它只在进 App 时出来一下，藏起来以后才显示状态信息；系统不告诉 App 它藏没藏，进 App 后等 1 秒算它藏了。各个窗口只给标题栏的信息（标题和次要信息，不放图标）、内容、控制区里的东西和状态信息。Mac 上标题栏靠左，次要信息在标题右边，卡片的拖动把手叠在这一条上；iPhone 上居中，次要信息在标题下面、小一号，左边是拉开侧边栏的按钮（从左边缘往右滑也行）。iPhone 上从控制区往上拖拉出 action 栏，打字时不拉，横着拖不算；拉开、收起侧边栏和 action 栏照系统可交互转场的做法分两段（`PhoneLayout.swift`）：拖着时窗口跟手，越过一半轻震一下，推过完全打开还能再出去一截、越推越吃力；松手时甩得够快就去甩的那头，不然看过没过半，用弹簧带着手指的速度走过去，甩得越快回弹越多；点按钮、点窗口收起没有速度，不回弹；走的途中按住就从当时的样子接着拖。抽屉动的时候窗口里不重新排版：窗口里一直照铺满屏幕、让着状态栏和 Home 条排，只变缩放、位置和裁掉多少，拉 action 栏时对话和控制区往上挪、跟着窗口底边走（`WindowLift`）；让出的安全区要是逐帧变，对话每一帧都得重排；打字时点控制区以外的地方收起键盘。还没做的窗口（文件、终端、预览）标题栏是窗口的名字，内容是占位，控制区是一张空卡片。字号是两端共用的一套 token，每个对应一种系统文本样式。

会话窗口（`SessionPane.swift`）：标题栏是会话的标题和所在的项目，内容是对话，控制区是输入框和一行按钮，状态信息是在不在干活、上下文用了几成、工作区改了多少行（假数据）。

- 控制区：上面一行是输入框；下面一行左边是 effort 的当前档位（low、medium、high、extra、max），iPhone 上按下它、Mac 上鼠标移上去，刻度线从左到右一根根展开在档位名前面（展开、收起都是先快后慢扫过去；展开没播完时手指拖得比它快，就快进到手指处），当前档位落在手指下面（左边放不下就贴着左边）；没拖就松手留着展开，按着横着拖是调档位，手指在哪一格就是哪一格，松手选定、收起；右边是附件、斜杠命令、语音输入（还没做），有字时多一个发送，回合在跑时多一个打断。
- 人发的消息（`MessageBubble.swift`）：靠右带气泡，右下角圆角小一点；排队中（agent 还没收到）只描边，收到了填上底色，气泡大小不变；正文原样显示，只把 ``` 围起来的一段排成等宽，斜杠命令的命令名用主题色，太长的折起来，图片和文件排在气泡上面。排队中的消息不是记录，单独放在 `Transcript.pending`，收到的那一刻才变成记录。
- agent 的话铺满这一栏，Markdown 用 Foundation 自带的解析、逐块排版（`Markdown.swift`）。两段话之间 agent 做的事折成一行，点开列出每一步，每一步再点开看参数和结果（`WorkViews.swift`）；每个工具怎么说、归哪一类在 `ToolPresentation.swift`，认不出的工具（项目自己的 MCP 等）列出参数和结果原文。
- 操作栏（`ActionBar.swift`）：iPhone 上点一条消息或 agent 的话、Mac 上右键弹出（Mac 上左键留给选字，开着文字选择的字会吃掉单击）。一个液态玻璃胶囊，一排图标按钮，出现时从贴着这一行的角整体等比放大；是浮层，不挤开别的内容，和这一行的一边对齐，平常在底下，底下会压到控制区或窗口底边时放到上面；再来一下、点别处或者滚动时收起。排队中的消息是立即发送、编辑、取消发送，收到了的是编辑、回退到这条之前（再选对话和代码、只回退对话、只回退代码）、从这里分叉，都有复制；agent 的话是复制、翻译、从这里分叉（后两个还没做）。
- 选字：iPhone 上气泡的正文和 agent 的话用 UIKit 的文本视图排（`SelectableText.swift`）：长按本身什么都不做，长按以后接着拖就从按下的字开始选字、操作栏收起，松手留着选区和系统的编辑菜单；agent 的话里连续的段落、标题、引用、列表项在同一个文本视图里，代码块、表格、分隔线照旧用 SwiftUI 排，选字跨不过它们。
- 发送：输入框里的字模糊淡掉，气泡连同附件从下往上浮进来、淡显，和对话往上滑同时开始。空闲、前面也没有排着没收到的时候发的开启新的一轮：对话滑到这条消息停在可见区顶上，最后一轮至少占满一屏，不够就在底下留白，回复往空白里填。回合在跑、或者前面还排着别的时发的是排在后面的：接在最后面，对话滑到最底下把它顶上来，不另留空白，收到时并进那一轮。打断后排着的几条一起开启新的一轮。
- 滚动（`TranscriptScroll.swift`）：打开时停在最底下，跟着最底下；往上翻就不跟了，翻回最底下又跟。内容或可见区变高变矮（展开收起一步、回复变长、键盘、抽屉）时，停在最底下、底下也没露着留白，就按底部对齐：最后几行跟着键盘一起顶上去，展开收起一步时最底下不动；不然按顶部对齐，对话不动。留白是人往上翻多少裁掉多少，裁到最后一条内容为止，下一次开启新一轮才重新留。做法都是在 iPhone 模拟器上用单独的探针 app 逐帧记位置试出来的，每一条的理由写在这个文件开头：对齐交给滚动视图（`defaultScrollAnchor` 的 sizeChanges，按状态换），不在回调里自己滚；滚动位置平时只留一个钉住的位置；可见区变矮时留白等键盘的动画走完再缩；留白在排版里和新消息一次算出来（`TranscriptStack`）。
- 假数据：会话记录的形状照统一格式的要点（`Transcript.swift`），kited 还没给出记录，现在显示 `SampleTranscripts.swift` 里的假数据：把 Kite 会话里有的工具都调了一遍，另有回合正在跑、不写代码的项目、空会话、压缩打断出错几个会话，人发的消息各种样子都有。发消息、打断、撤回、回退只改假数据：回合没在跑时发的消息过一会儿算收到（`Session.send`），在跑时一直排着，直到打断或立即发送。

## 约定

- 工程照 Xcode 自带的「多平台 App」模板的设置写成，不用 XcodeGen 这类生成工具。`Kite/` 是同步文件夹：在里面加、删、挪文件，工程自动跟上，不用改 `project.pbxproj`。
- 两端共用代码，差异用 `#if os(macOS)`、`#if os(iOS)` 分开。
- Swift 6 语言模式，数据竞争在编译时报错；模板默认是 5。默认隔离在主线程（`SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor`），和模板一致。
- 开发语言是简体中文（`zh-Hans`），界面文字直接写中文。
- 最低 macOS 26、iOS 26。只支持 iPhone，要 iPad 时把 `TARGETED_DEVICE_FAMILY` 改成 `1,2`。
- Mac 版开沙盒，允许对外连网（连 kited）、只读用户选中的文件，和模板一致。
- Bundle ID 是 `com.sainner.kite`。

## 编译和运行

`.kite/check` 在 `app/` 有改动时编译两端，出错时列出文件和行号。手动编译：

```bash
xcodebuild -project app/Kite.xcodeproj -scheme Kite -destination 'generic/platform=macOS' -destination 'generic/platform=iOS Simulator' build -quiet
```

运行用 Xcode 打开 `app/Kite.xcodeproj`，选 My Mac 或一台 iPhone 模拟器。
